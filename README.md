# GhostWork Buddy

Workplace assistant with chat and automations.

## Features

- Chat assistant
- Automation management
- Admin dashboard, Supabase back-end

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/ghostwork-buddy.git
cd ghostwork-buddy
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
